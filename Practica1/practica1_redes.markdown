## Comandos Utilizados para Configuración de Switches

Ejemplo de configuración aplicada a cada switch con su nombre y contraseña:

```plaintext
enable
configure terminal
hostname SW_L1_RECEPCION
enable secret 201903873
line console 0
password 201903873
login
exit
service password-encryption
end
write memory
```
